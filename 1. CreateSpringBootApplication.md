# Spring boot Demo Application

I created this application using [JHipster](https://www.jhipster.tech/), following [Matt Raible's](https://www.youtube.com/watch?v=IfyjKCt6YHE) tutorial. You can check the [activity log](activity-log/1.1.create-spring-boot-application.log) for details on the creation process.

## Tech Stack Overview: Three-Tier Architecture

- **Presentation Layer**: React(Client-side) 
- **Application Logic Layer**: Spring Boot(Business Logic)
- **Data Layer**: PostgreSQL(Database)
